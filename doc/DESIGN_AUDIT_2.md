| 级别 | 数量 | 性质 |
|---|---|---|
| A 规则缺失 | 10 | 实现时必然产生歧义，两人写出两套行为 |
| B 数值缺失 | 12 | 缺参数，对应系统无法编码 |

**结论：规则层仍不闭合。配方与数值已可编码，但状态机（何时扣料、何时返还、何时结算）与状态迁移（周目重置范围）没有定义，这两块是当前最大的实现风险。**

## A 类 · 规则缺失

### A1 输入扣取时机未定义

§6.1~§6.6 定义了槽位、堵塞、优先级、电力、流体、副产物，全文没有出现「何时扣除输入」。

两种实现行为完全不同：

| 方案 | 行为 | 后果 |
|---|---|---|
| 开始扣料 | 配方启动时一次性扣掉输入 | 半成品占用资源，停机时资源锁在进度条里 |
| 完成扣料 | 进度满时检查并扣料 | 可以「空转攒进度」，产能凭空放大 |

**修法**：写入 §6.1

```
配方在进度达到 1 时检查并扣除输入，同时产出。
若此时输入不足，进度停在 1，状态 = 断料，不产出。
```

### A2 配方切换时的进度与输入处置未定义

§6.1 写「修改分配立即生效，进行中的实例不重置」。

未定义：

- 切换配方后原进度是否清零
- 若采用 A1 的「完成扣料」，清零即无损失，玩家可随意试错

**修法**：写入 §6.1

```
切换配方：进度清零，不返还（完成扣料制下本就无已扣资源）。
清空槽位：同上。
```

### A3 配给优先级的粒度未定义

§6.3 只写「逐物品选择模式：优先级 / 比例」，未定义排序对象。

可能对象：建筑、槽位、配方、材料去向。

**修法**：写入 §6.3

```
优先级表的键 = (物品, 消费配方) 二元组，按玩家排序。
同一物品被多个配方消费时，按该表从上到下依次满足。
比例模式：按各配方的当前需求量等比分配，余数给排序靠前者。
```

### A4 弹药扣减时机自相矛盾

| 位置 | 表述 |
|---|---|
| §8.5 | 「本波胜利，扣除弹药」——波末一次性扣 |
| §13.7 | 「弹药在仓库扣减，不足时该炮塔停止输出」——逐秒扣 |

两处互斥。

**修法**：§8.5 改为逐秒扣

```
每 tick：按弹药消耗速率扣减仓库对应弹种，不足则该炮塔本 tick 无输出。
波次结束时不再额外扣减。
```

### A5 波次进行中断线的处置未定义

§8 全文未提断线。§7.8（离线结算）只说离线不触发战斗。

三种可能：判负、暂停、继续模拟。挂机游戏应选暂停。

**修法**：写入 §8.3

```
断线：波次暂停，推进与弹药消耗停止。重连后从当前波继续。
断线超过 30 分钟：本波判负，已消耗弹药不退。
```

### A6 离线大步长下的库存上限规则未定义

§7.8 定「固定步长 60 秒批量模拟」。60 秒内一个 0.5 秒配方可执行 120 次，远超仓库余量。

未定义超限部分如何处理：截断、溢出丢弃、还是回退到按容量能执行的最大次数。

**修法**：写入 §7.8

```
单步内可执行次数 = min(floor(步长 / 配方时间), 按输入与仓容可支持的最大次数)
不足一次则步内不执行，进度跨步累积。
```

### A7 前哨存在理由未定义，且母星矿脉永不枯竭

§13.4 定母星每种矿初始储量 50,000,000。

实际消耗估算：后期铁板 15/秒，铁矿石同速率，单小时 54,000。50,000,000 需 926 小时才耗尽。全流程约 55 小时，消耗不足 6%。

结果是 §6.9 的贫化递减永不触发，§9.6 的采矿前哨失去动机。

**修法**：分两级矿脉

| 位置 | 矿种数 | 单矿储量 | 说明 |
|---|---|---|---|
| 母星 | 全 6 种 | 2,000,000 | 后期铁铜会在 30~45 小时进入贫化 |
| 前哨 | 1~2 种 | 12,000,000 | 单一矿种高产，按星系 biome 偏向 |

### A8 前哨的电力与建造队列未定义

§9.6 允许前哨建太阳能与火电，但未说明前哨是否有独立电网、是否与母星共享建造队列、建筑成本是否同一套。

**修法**：写入 §9.6

```
前哨为独立星球实例：独立电力、独立仓库、独立建造队列（与前哨并行）。
建筑等级、成本、槽位规则与母星一致。
前哨不参与主线任务中的「建筑总数」统计。
```

### A9 模块与停用的交互未定义

§4.1 定义 `enabled: false`「不耗电、不产出、不计入合计」，未定义：

- 停用后已占用的模块是否退回
- 停用是否影响电力统计中的「装机容量」

**修法**：写入 §4.1

```
停用：模块保留在原实例上，不退回；该实例的发电输出不计入装机容量。
```

### A10 槽位数量与「×N」记法歧义

§4.1 的 `Slot` 无数量字段，一个槽位对应一个配方实例。§6.1 的示例却写作：

```
装配机 Lv8
├─ 电路板 ×4
├─ 铁齿轮 ×2
└─ 空 ×2
```

「×4」可读作「4 个槽位」或「单槽批量 ×4」，两种读法的产能差 4 倍。

**修法**：§6.1 示例改为列出槽位数

```
装配机 Lv8（8 槽）
├─ 电路板   占 4 槽
├─ 铁齿轮   占 2 槽
└─ 空       2 槽
```

- 继承哪一项由谁指定（发射时选择，还是系统取最高）
- 载荷可以叠加吗（同一载荷装 2 份）

### C3 星门的作用失去依托

§9.3 定深核议会声望来自「星门过路费累计」，但：

- §9.7 前哨运输是「按距离效率」自动结算，未经过星门
- 玩家之间无对抗，无舰队穿越需求

结果：过路费无人支付，深核议会声望永不增长，星门成为装饰。

**修法**：二选一，需固定一条。

```
A. 前哨航线若跨星区，自动经星门并按次扣过路费（进入维护费，计入深核议会声望）
B. 删除星门与深核议会声望来源，星门仅作为星图地标
```

### C5 成就系统未设计

§14.1 写「增加工厂与塔防成就」，全文无成就定义。而 §10 已有 121 个任务，两者职责重叠。

**修法**：明确成就只承载「非进度类里程碑」（如单波零损失、单星满产能），任务承载主线。

### C6 建筑停用缺少使用场景

§4.1 定义 `enabled`，但全文没有需要停用的地方。要么给出场景（如省电、波次前停机），要么删除该字段。

### C7 装备网格规则未定义

§11.2 给了尺寸与效果，未定义：

- 是否可旋转
- 是否可重叠
- 工程服升级后超出新网格的装备如何处理

**修法**：写入 §11.2

```
装备不可旋转、不可重叠、不可越界。
升级工程服时，超出新网格的装备自动卸下并退回仓库。
```

### C8 `maxSpace` 字段去向未定义

现有 `Planet.maxSpace` 与 `maxFleetStorage` 在新体系中无对应规则，而 §4.1 已用实例数（64）与仓库上限替代。

**修法**：写入 §14.2，标明两字段删除。

### C9 弹药耗尽后波次是否判负未定义

§13.7 只写「该炮塔停止输出」。若全部炮塔停火，锈群按推进速度走完防线，需要 40~160 秒空转。

**修法**：写入 §8.5

```
全部炮塔在连续 10 秒内无输出时，本波立即判负。
```

### C10 建筑速度未定义

§4.3 只给了石炉 50%、电炉 100%，其余 19 种建筑无速度值。

**修法**：§4.3 补一列，未标注者一律 100%。

### C11 波次期间炮塔是否耗电未定义

§13.3 电力表未列炮塔。若耗电，夜间防守会出现欠压；若不耗电，电力与防御解耦。

**修法**：明确一条并写入 §13.3。

### C12 配方「实际产能」的统计口径未定义

§6.7 诊断面板有「理论产能 / 实际产能」两列，未定义实际产能如何取值（滑动窗口均值？上一 tick？）。

**修法**：写入 §6.7

```
理论产能 = 槽位数 / 配方时间
实际产能 = 最近 60 秒的产出总量 / 60
```

## D 类 · 规模与体验

### D1 槽位规模超出可操作范围

§4.1 允许 64 实例，单类型 8 座 × 16 槽 = 128 槽，全星球理论上千槽。

未设计批量操作，玩家需要逐槽点击。

**修法**：新增「产线模板」：保存一组（建筑类型 → 配方槽位分配），一键套用到同类实例。

### D2 任务密度未按小时校验

§10.2 声称每 20~30 分钟一个任务，但 121 个任务 ÷ 55 小时 = 每 27 分钟一个，是按平均算的。

实际分布：第 3 章 20 个任务覆盖 8 小时 = 每 24 分钟；第 6 章 16 个覆盖 10 小时 = 每 37 分钟。第 6、7 章明显偏稀。

**修法**：第 6 章补至 20 个，第 7 章补至 20 个，总数 129。

### D3 离线上限与总时长冲突

§7.8 单次离线最多 12 小时。55 小时流程 = 5 次满额离线即可覆盖大半。

**修法**：离线按 60% 效率结算，或把上限降到 8 小时。

### D4 波次挑战总耗时过长

40 波需 8 次挑战（每次最多 5 波），间隔冷却 30 分钟 = 至少 4 小时纯等待。

**修法**：冷却改为按波次计（通过第 N 波后可立即挑战 N+1），冷却只作用于重复挑战。

### D5 40 波上限与无限研究冲突

§8.4 波次上限 40，§7.4 无限研究无上限。打完 40 波后，武器伤害无限研究失去唯一用途。

**修法**：波次上限随扰动提高（扰动等级 × 8，最高 64），或明确无限武器研究仅用于舰队。
