## 关键设计决定

| 主题 | 决定 |
|---|---|
| 距离口径 | 方案 C：`2700 + 航线长度 × 20 + 星门数 × 12 万`，默认 `legacy`，环境变量切 `v2` |
| 视觉与玩法坐标 | 分离：3D 视图的旋臂/深度只做视觉，不参与任何距离计算 |
| 跃迁保留 | 科技 / 成就 / 军官保留，星球拆除，发补给包 |
| 冻结层 | 无命令活动的周目降频到每 30 tick 一次 |
| 星门经济 | 中立免费；玩家所有收费；NPC 派系收费回收 |

## 验收命令

```bash
pnpm test          # typecheck + i18n + 引擎/周目/星图/服务端 四套冒烟
pnpm build         # 生产构建
pnpm build:node-server
```

冒烟覆盖的核心断言：

- 布局确定性、16 星区连通、寻路、经济修正、跳数
- 扫描 / 命名 / 星门归属 / 占领 / 过路费 / 封锁 / 商队
- 航线距离（legacy 与 v2 双向切换）、多段推进、返程时间
- 周目跃迁（倒计时、星门前置、排行榜）、未知信号、虫洞

## 体验入口

```bash
pnpm dev
# 3D 星图：http://localhost:25121/#/starmap
# 星系页：http://localhost:25121/#/galaxy
```

3D 星图操作：拖拽环顾、`W/S` 前进后退、`A/D` 平移、`Q/E` 升降、`Shift` 加速、滚轮调速；
预设按钮：母星 / 银河全景 / 旋臂巡航 / 银心。
