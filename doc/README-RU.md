## О проекте

**OGame Vue TS · Версия с переработанным сетевым режимом** — космическая стратегическая игра, созданная в результате дальнейшей разработки открытого проекта [ogame-vue-ts](https://github.com/setube/ogame-vue-ts) автора [setube](https://github.com/setube).

В проекте сохранены одиночный режим и ключевая система игровых параметров оригинала, при этом архитектура сетевой игры, интерфейс, вид галактики, система баз и способы развёртывания были существенно переработаны и расширены.

В текущей версии доступны два режима работы:

- **Одиночная игра**: игровое ядро работает в браузере, сохранения хранятся локально — можно играть сразу, без дополнительной настройки;
- **Сетевая игра**: единственным авторитетным источником состояния выступает сервер Node.js WebSocket; поддерживаются аккаунты, совместная игра нескольких пользователей на одном сервере, PvP, чат, таблицы лидеров и экосистема NPC.

> В настоящее время проект поддерживает только схему **«веб-клиент + Docker на fnOS»**. Устаревшие варианты развёртывания — Android, Electron и Go-сервер — удалены; соответствующий код можно найти в истории Git.

## Ключевые возможности

### База и управление империей

- Строительство, исследования, верфь и оборона объединены в единую базу;
- Очереди строительства и исследований, слоты флотских миссий и расход ресурсов рассчитываются в реальном времени;
- Лунная база, формирование лун, поля обломков и механика их переработки;
- Система офицеров, бонусы к ресурсам, очки империи и управление несколькими планетами.

### Флот и бои

- Строительство кораблей, формирование флотов, отправка миссий и многоэтапные перелёты;
- Симулятор боя позволяет проверить конфигурацию флота до вложения ресурсов;
- Боевые отчёты, трофеи, поля обломков и расчёт результатов атаки и обороны;
- Захват звёздных врат, плата за проход, блокады и NPC-караваны.

### Дипломатия и экосистема NPC

- Отношения с NPC, уровень расположения, торговля, подарки, разведка и дипломатические события;
- Враждебные NPC проводят разведку, атакуют и мстят;
- Развитие NPC, экономическое производство и общий мир для нескольких игроков;
- Дипломатические уведомления, отчёты о событиях и фильтрация по статусу отношений.

### Галактика и освоение

- Полноэкранная 2.5D-карта галактики с тремя уровнями обзора: звёздная система, локальная галактика и панорама всей галактики;
- 10 планет медленно обращаются вокруг звезды; их орбиты, размеры и скорости задаются случайным образом;
- При нажатии на планету или звёздную систему камера фокусируется и следует за объектом, а контекстная панель плавно появляется;
- Сканирование, присвоение имён, звёздные врата, неизвестные сигналы, червоточины, обломки и исследование руин;
- Циклическая вселенная: 12 игровых циклов × 16 секторов × 64 звёздных систем.

### Сетевая игра и долгосрочная эксплуатация

- Регистрация аккаунта и вход в него, сессии и переподключение после обрыва связи;
- Авторитетный мир на сервере; клиент синхронизируется с ним командами и патчами состояния;
- Торговля между игроками, PvP, разведка, ракеты, флотские миссии и уведомления в реальном времени;
- Общий и личный чат, статус «онлайн», таблицы лидеров и механика сезонов и игровых циклов;
- JSON-сохранения на сервере, автоматическое сохранение и постоянное хранение в томе Docker.

### Пользовательский опыт и сопровождаемость

- 8 языков: упрощённый китайский, традиционный китайский, английский, немецкий, русский, испанский, корейский и японский;
- Тёмная и светлая темы оформления, адаптивная вёрстка и PWA;
- Сохранение одиночной игры в IndexedDB;
- Единый слой команд, headless-ядро и тестируемый слой игровых правил;
- Развёртывание на fnOS через Docker в один клик и экспорт образа.

## Архитектура одиночного и сетевого режимов

```text
┌────────────────────────────────────────────────┐
│               Браузерный клиент                │
│   Vue 3 + Pinia + Vue Router + Tailwind CSS    │
│  Слой представления только отправляет команды  │
│  и не изменяет состояние мира напрямую         │
└──────────────────────┬─────────────────────────┘
                       │
             ┌─────────┴─────────┐
             │                   │
      Одиночный режим      Сетевой режим
             │                   │
             ▼                   ▼
┌──────────────────────┐     WebSocket
│      src/core        │         │
│    headless-ядро     │         ▼
│   tick / команды     │   Node.js-сервер
│  правила / состояние │   server/ + ws
└────────────┬─────────┘         │
             │                   │
             ▼                   ▼
        IndexedDB        Авторитетный мир
                            на сервере
                          data/world.json
```

- `src/core`: headless-ядро игры, отвечающее за состояние мира, tick, миссии, NPC, команды и протокол;
- `src/logic`: чистые игровые правила и числовые расчёты, по возможности не зависящие от UI;
- `server/`: сервер Node.js WebSocket, аккаунты, комнаты, хранение данных и раздача статических ресурсов;
- `src/stores` / `src/views`: состояние и интерфейс браузерного клиента;
- `scripts/`: smoke-тесты headless-ядра, тесты сервера и скрипты сборки.

В одиночном режиме напрямую используется headless-ядро; в сетевом режиме то же ядро работает на сервере, а клиент лишь отправляет команды и отрисовывает снимки состояния.

## Быстрый старт

### Требования

- Node.js **22+**
- pnpm **10+**
- Современный браузер (Chrome / Edge / Firefox / Safari)

### Клонирование и установка

```bash
git clone https://gitee.com/shilianlvke/ogame-vue-ts.git
cd ogame-vue-ts
pnpm install
```

Зеркало на GitHub:

```bash
git clone https://github.com/shilianlvke/ogame-vue-ts.git
```

### Локальная разработка

```bash
pnpm dev
```

Адрес разработки по умолчанию:

```text
http://localhost:25121
```

### Сборка для продакшена

```bash
pnpm build
pnpm preview
```

`pnpm build` сначала выполняет проверку типов TypeScript, а затем собирает статические ресурсы фронтенда в `docs/`.

### Локальный запуск сервера сетевой игры

```bash
# Сборка фронтенда и сервера Node.js
pnpm build
pnpm run build:node-server

# Запуск сервера (по умолчанию читает docs/ и data/)
pnpm start:server
```

Порт по умолчанию — `25122`; его можно переопределить с помощью переменных окружения:

```bash
PORT=8080 STATIC_DIR=docs DATA_DIR=data pnpm start:server
```

После запуска сервера доступны:

- Игровая страница: `http://localhost:25122`
- Проверка работоспособности: `http://localhost:25122/health`
- WebSocket: `ws://localhost:25122/ws`

> В продакшене используйте HTTPS/WSS и самостоятельно обеспечьте контроль доступа, резервное копирование и усиление безопасности.

## Развёртывание сетевой игры

В настоящее время рекомендуется развёртывание через Docker на fnOS.

### Способ 1: развёртывание из исходников на fnOS в один клик (рекомендуется)

Предварительные условия: на fnOS установлены Docker и git; образ `node:22-alpine` можно загрузить, либо настроено зеркало реестра Docker, ускоряющее загрузку.

```bash
cd /vol1/docker
git clone https://gitee.com/shilianlvke/ogame-vue-ts.git ogame
cd ogame

chmod +x deploy-fnos.sh
./deploy-fnos.sh
```

Последующие обновления:

```bash
./deploy-fnos.sh --update
```

Другие команды:

```bash
./deploy-fnos.sh --start
./deploy-fnos.sh --stop
./deploy-fnos.sh --restart
./deploy-fnos.sh --logs
./deploy-fnos.sh --status
./deploy-fnos.sh --port 8080
./deploy-fnos.sh --china
```

### Способ 2: сборка образа на компьютере и его импорт

Windows:

```powershell
.\docker-build.ps1
```

Скрипт собирает образ `noskyman:latest` и экспортирует его в `noskyman.tar`. Скопируйте `noskyman.tar` и `docker-compose.yml` в один каталог на fnOS, после чего выполните:

```bash
docker load -i noskyman.tar
docker compose up -d
```

Полные инструкции, описание переменных окружения, настройка обратного прокси для WebSocket и ответы на частые вопросы приведены здесь:

- [Документация по развёртыванию в Docker на fnOS](DEPLOY_DOCKER.md)

> `docker-compose.yml` использует только локальный образ `noskyman:latest` и не загружает образы из сети автоматически; сборка из исходников выполняется скриптом `deploy-fnos.sh`.

## Структура проекта

```text
.
├── src/
│   ├── core/          # headless-ядро игры: мир, tick, команды, миссии, NPC, протокол
│   ├── logic/         # чистые игровые правила и расчёты
│   ├── components/    # компоненты Vue
│   ├── views/         # страницы интерфейса
│   ├── stores/        # состояние Pinia
│   ├── locales/       # тексты на 8 языках
│   ├── services/      # сохранения, обновления, WebDAV и другие сервисы
│   └── workers/       # Worker боевой системы
├── server/            # сервер Node.js WebSocket
├── scripts/           # сборка, i18n, smoke-тесты headless-ядра и сервера
├── doc/               # развёртывание, сетевая игра, проектирование галактики и справочные материалы
├── public/            # статические ресурсы
├── Dockerfile         # многоэтапный образ: фронтенд + сервер Node.js
├── docker-compose.yml # конфигурация запуска на fnOS
├── deploy-fnos.sh     # скрипт развёртывания на fnOS в один клик
└── docker-build.ps1   # сборка и экспорт образа в Windows
```

## Основные скрипты

| Команда | Описание |
|---|---|
| `pnpm dev` | Запуск сервера разработки Vite |
| `pnpm build` | Проверка типов и сборка фронтенда в `docs/` |
| `pnpm preview` | Предпросмотр продакшен-сборки |
| `pnpm typecheck` | Проверка типов TypeScript |
| `pnpm check:i18n` | Проверка ключей в 8 языковых пакетах |
| `pnpm test` | Проверка типов + i18n + все smoke-тесты headless-ядра и сервера |
| `pnpm smoke` | Smoke-тесты headless-движка |
| `pnpm smoke:server` | Интеграционный тест настоящего сервера WebSocket |
| `pnpm build:node-server` | Сборка сервера Node.js в `server-dist/` |
| `pnpm dev:server` | Сборка и запуск локального сервера Node.js |
| `pnpm start:server` | Запуск уже собранного сервера Node.js |

## Тестирование и качество

```bash
pnpm typecheck
pnpm check:i18n
pnpm test
```

`pnpm test` охватывает:

- headless-движок игры;
- область действия игровых циклов;
- масштаб звёздной карты, детерминированность, компоновку и связность;
- аккаунт максимального уровня и прохождение кампании;
- вход на сервер, видимость, команды, патчи, tick, сохранения и переподключение;
- синхронизацию клиента и реальный канал WebSocket.

- полноэкранный 2.5D-вид галактики и интерактивная фокусировка;
- расширение игровых механик: галактики, игровые циклы, звёздные врата, неизвестные сигналы и др.;
