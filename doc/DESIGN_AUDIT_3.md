| 级别 | 数量 | 性质 |

**结论：整套「产出」链路已闭合，「使用」链路没有。** 材料能被配方自动消费，但掉落物、装备、模块、载荷四类物品进入仓库后没有任何使用入口。

## A 类 · 物品与使用路径

### A1 四类物品缺少使用入口

规划书定义了 63 种材料，全部存于行星仓库。其中四类不是「被配方消费」的材料，但全文没有任何「怎么用」的定义：

| 物品 | 现状 | 缺口 |
|---|---|---|
| 破损蓝图 | §3.3 写「直接解锁 1 项科技」 | 无使用动作、无选项目界面、无触发时机 |
| 装备 | §11.2 有尺寸、效果、成本 | 无制造入口、无装备动作、无卸下动作 |
| 模块 | §4.1 有 `modules` 字段，§6.10 有槽位上限 | 无装入动作、无拆除规则、无退回规则 |
| 锈群核心 | §8.8 写「高级科技与高级建筑升级需要」 | 未列出哪些科技、哪些建筑、各需几个 |

**修法**：新增 §3.4「持有与使用」，确立一条总规则：

```
不设背包。全部物品存放于行星仓库，通过对应面板的入口使用。
```

| 物品类 | 存放 | 使用入口 |
|---|---|---|
| 材料 | 行星仓库 | 无，被配方自动消费 |
| 模块 | 行星仓库 | 建筑详情 → 模块槽 |
| 装备 | 行星仓库 | 角色面板 → 装备网格 |
| 载荷 | 行星仓库（独立计数） | 发射井 → 载荷配置 |
| 破损蓝图 | 行星仓库 | 科技面板 → 使用 |
| 锈群核心 | 行星仓库 | 科技面板 / 建筑升级面板 |

### A2 载荷身份矛盾

§12.2 把五种载荷写成「额外成本」（发射时扣材料），但：

- 任务 7-9~7-12 把它们当奖励物发放（`数据核心 ×1`）
- 任务 7-19 要求「持有 星图阵列 ≥1」
- 任务 7-20 要求「持有 数据核心 ≥1、工业种子 ≥1」

同一样东西既是发射成本又是可持有物品，两处互斥。

**修法**：载荷定为**独立物品**，不进 `MaterialId`，单独计数。

| 载荷 | 制造配方 | 时间 | 发射时 |
|---|---|---|---|
| 种子舱 | 钢材 ×100 | 30 秒 | 必需，消耗 1 |
| 数据核心 | 处理单元 ×50 | 20 秒 | 可选，消耗 1 |
| 工业种子 | 低密度结构 ×50 | 20 秒 | 可选，消耗 1 |
| 物资舱 | 钢材 ×500 | 30 秒 | 可选，消耗 1 |
| 星图阵列 | 处理单元 ×200 + 太阳能板 ×50 | 60 秒 | 可选，消耗 1 |

由装配机以 `payload` 类别制造，存入仓库独立计数区。

### A3 装备没有制造入口

§11.2 给了五种装备的成本与解锁科技，但没有说在哪制造，也没有说装备是物品还是状态。

**修法**：装备由装配机以 `craft` 类别制造，成品进入行星仓库。

| 装备 | 制造时间 | 能耗 |
|---|---|---|
| 太阳能板（个人） | 5 秒 | 150 |
| 电池（个人） | 5 秒 | 150 |
| 外骨骼 | 20 秒 | 210 |
| 个人机器人 | 30 秒 | 210 |
| 便携核反应堆 | 40 秒 | 420 |

### A4 模块没有安装与拆除规则

§6.10 只写「模块装入建筑，作用于该建筑全部槽位」，未定义装入方式、拆除方式、退回方式、替换方式。

**修法**：写入 §6.10

```
装入：从行星仓库扣 1 个模块，填入该建筑的模块槽。
拆除：模块退回行星仓库，立即生效。
替换：先拆除再装入，不额外收费。
上限：模块槽位 = 建筑等级 / 4（向下取整），装满后不可再装。
```

### A5 锈群核心未指定消耗点

§8.8 只给总量 12，没有说这 12 个消耗在哪。

**修法**：写入 §8.8

| 消耗点 | 数量 |
|---|---|
| 第 6 层 4 项科技（核能 / 火箭 / 发射井 / 无限研究），每项 2 个 | 8 |
| 火箭发射井升级至 Lv5 / Lv10 / Lv15 / Lv16，每级 1 个 | 4 |
| 合计 | 12 |

## B 类 · 机制矛盾

### B1 无限研究被周目重置清空

§7.4 定「火箭首次发射后解锁」。
§12.3 重置表定「42 项科技全部清零」。

发射是周目重置的触发条件，所以无限研究解锁的同一刻就被清空，机制自毁。

**修法**：无限研究独立于 42 项科技，跨周目保留。

```
无限研究不占用 42 项科技的名额，记录在单独的 infiniteResearch 字段。
周目重置不清空该字段。
解锁条件改为：首次发射火箭后永久解锁。
```

### B2 配方类别与建筑的映射未定义

§5.1 定义 `category: 'smelt' | 'craft' | 'chem' | 'oil' | 'science' | 'military'`，但：

- 拆解配方（§5.3）不属于任何一类
- 科技包属于 `science`，但没说是哪座建筑能跑
- 弹药属于 `military`，同样没指定建筑

**修法**：`category` 扩充为 7 类，并补映射表

| 建筑 | 可跑类别 |
|---|---|
| 石炉 | smelt |
| 电炉 | smelt |
| 装配机 | craft、science、military、payload |
| 化工厂 | chem |
| 炼油厂 | oil |
| 离心机 | chem |
| 拆解机 | salvage |

新增类别：`salvage`（拆解）、`payload`（载荷）。

### B3 实验室的研究分配未定义

§4.3 写「实验室槽位 = 并行研究数与速度」，但没说玩家如何指定某个槽位研究哪一项科技。

按 §13.8，实验室每槽每秒产生 1 个研究单位。若 4 个槽同时对 4 项科技供料，消耗如何分摊，未定义。

**修法**：实验室的槽位与生产建筑一致，逐槽指定科技。

```
每个槽位指定 1 项科技，进度 = 该槽贡献的研究单位。
同一科技可占多个槽位，进度叠加。
未指定科技的槽位空转，不消耗科技包。
科技完成后其占用的槽位清空。
```

### B4 仓库满时的掉落处理未定义

§8.6 的掉落直接进入仓库。若仓库已满（如锈蚀合金 200/200），掉落是丢弃、暂存还是阻止挑战，未定义。

**修法**：写入 §8.6

```
掉落物按顺序写入仓库，超出上限的部分直接丢弃。
挑战开始前若仓库余量不足以容纳最低掉落量，提示玩家。
```

### B5 建筑拆除无规则

§4.1 提到「超出时提示拆除」，但拆除是否返还、返还多少、槽位进度如何处理，全文未定义。

**修法**：写入 §4.1

```
拆除实例：返还 baseCost 的 50%（向下取整），模块退回仓库，槽位进度丢弃。
拆除不消耗时间，立即生效。
```

### B6 市场没有结算货币

§9.2 给出成交价公式，但全文没有货币定义。63 种材料之间如何支付、手续费从哪扣、买卖差额记在哪，均未定义。

现有资源中 `darkMatter` 是跨周目货币，不适合承担日常交易。

**修法**：新增市场货币「星币」，与材料体系隔离。

```
获取：卖出材料
消耗：买入材料、支付手续费
存储：玩家账户字段 credit，不占仓库
兑换：星币不可兑换为任何材料，只在市场内循环
周目：星币跨周目保留
```

星币与材料单向隔离，避免市场波动传导到产线。

## C 类 · 规则细则

| ID | 项 | 缺口 | 修法 |
|---|---|---|---|
| C1 | 破损蓝图选哪项科技 | 未定义是随机还是玩家选择 | 玩家从「前置已满足且未完成」的科技中选择 1 项，立即完成 |
| C2 | 装备重复持有 | 未定义同类装备能否装 2 个、效果是否叠加 | 可持有多个，网格内同类装备只生效 1 个，多余的无效但不移除 |
| C3 | 前哨产物与母星仓容 | 运输到达后母星仓库满时如何处理 | 停在航线，保留在前哨仓库，状态标记「待转运」 |
| C4 | 货船分配粒度 | 「分配至航线的货船总货舱」按数量还是按舰船 | 按数量，从舰船池扣除，可随时增减 |
| C5 | 舰队任务槽位 | 运输改为自动后，任务槽位是否保留 | 保留，用于远征、殖民、回收；前哨运输不占槽位 |
| C6 | 市场撮合与做市 | 只有 10 名玩家，某材料可能长期无对手方 | 矿业公会常驻买卖盘，深度 5000 单位/种，价格 = 基础价 × 0.95；玩家单优先成交 |
| C7 | 拆解机的随机与存档 | 随机矿石何时抽取，重放是否一致 | 配方完成时按权重抽取，结果写入槽位 `outputItem` 字段，存档可复现 |
| C8 | 排行榜指标 | 「产能、发射次数、波次进度」无计算口径 | 产能 = 最近 1 小时平均每秒产出材料的基础价之和；发射次数 = 累计；波次 = 历史最高通过波次 |
| C9 | 第二周目任务奖励 | 任务表重头开始，奖励可重复领取 | 可重复领取，属于周目循环的一部分；成就与暗物质不重复计算 |
